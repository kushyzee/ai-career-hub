# AI Career Hub v0.1.0

**The foundation is live.** This first release doesn't ship any real course
content yet, it ships the architecture that content will live in.

## What's in this release

- A reading-first module page: plain-language explanations, realistic
  examples, and a weak → good → excellent interview answer breakdown for
  every concept, each rendered with its own visual "verdict stamp."
- A full course index and a cross-referenced glossary, both generated
  automatically from module files, no manual list-keeping required.
- Persistent sidebar navigation on desktop, a slide-in drawer on mobile,
  breadcrumbs, and previous/next module links.
- Light and dark themes, built around a custom palette rather than
  framework defaults.
- A content system where adding a new module is just: write one Markdown
  file. No code changes required.

## What's next

Real course content is being written now. Once modules are wired in, that
release will be **v1.0.0**, the point where AI Career Hub actually does its
job: a complete, readable-end-to-end AI Evaluation Interview Prep course.
Everything after that (search, bookmarks, mock interviews, etc.) builds on
top of a finished product rather than toward one.

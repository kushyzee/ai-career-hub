# AI Career Hub v1.0.0

**The course is live.** All 16 modules of the AI Evaluation Interview Prep course are written, wired in, and readable end-to-end: Rubric Engineering, Operational Definitions, Fact-Checking Methodology, Claim Classification Systems, Rubric Calibration, Score Anchoring, Decision Framework Design, Annotation Guideline Writing, Edge Case Design, Error Taxonomy, Error Analysis, Documentation Standards, AI Response Evaluation Frameworks, Reproducibility, AI Safety Evaluation, and End-to-End Evaluation Workflow.

This is the milestone that matters most for a course site: it's no longer a scaffold waiting for content, it's a complete, navigable course someone can sit down and actually study from, start to finish.

## What's in this release

- All 16 modules, each with a plain-English explanation, workplace examples, a weak → good → excellent interview answer breakdown, and an interview cheat sheet
- Full navigation: persistent sidebar, mobile drawer, breadcrumbs, previous/next module, in-page jump-nav, every page reachable from anywhere
- A glossary auto-generated from every module's cheat sheet, cross-linked back to source modules
- Light and dark themes
- A handful of real bugs found and fixed while wiring in actual content: a parser that was silently dropping interview questions, and duplicate section headings.

## What's next

The V2 roadmap: search, hand-curated related modules, a reading progress bar, localStorage-based notes, bookmarks, and offline support. None of these are required to use the course, they're refinements on top of a finished product.
